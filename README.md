## №2 Анализ лог выражений
Здесь для анаиза используется алгебра логики. Самый простой способ решения - код на *python*.
Метод решения - вложеные циклы. 

> [!NOTE]
> Колличество вложеных циклов зависит от колличества переменных.

Программа просто строит табл истинности и сверяет значения с данными.

> [!IMPORTANT]
> Условия задания нет)

Решение:

```python
print("x y z w F")

for x in range(2):
    for y in range(2):
        for z in range(2):
            for w in range(2):
                F = (not y and x) and (z or not w)

                if F == 1:
                    print(x, y, z, w, int(F))
```

Начинающий исследователь Андрей Иванов захотел сделать небольшую презентацию, наглядно показывающую ситуацию в различных странах, за основу презентации он взял файл под названием «Результаты исследований». В данном файле приведена часть базы данных «Города и страны», которая детально описывает различные страны, города и языки. База данных состоит из трех таблиц. Таблица «Страны» содержит следующую информацию: код, название, континент, регион, площадь, год получения независимости, население, ОПЖ – ожидаемая продолжительность жизни, ВНД – валовый национальный доход, предыдущее значение ВНД, форма правления, идентификатор столицы. Таблица «Города» содержит следующую информацию: идентификатор, название, код страны, район, население. Таблица «Языки» содержит следующую информацию: код языка, код страны, название, является ли официальным, процент использования в стране. На рисунке приведена схема базы данных. <br>
> <br>Основываясь на информации из приведённой базы данных, помогите определить Андрею Иванову среднюю площадь стран Южной Америки (South America), в которых население столицы не превышает 150 000. Ответ округлите до целого числа по математическим правилам.

2) С помощью функции =ВПР(L2;Города!A:E;5;ЛОЖЬ) найдем населения всех столиц, с помощью фильтрации оставим только те столицы, население которых меньше или равно 150000. Получим ID столиц — 763, 3014, 3243.

3) Обратно перейдем на лист «Страны» и выберем страны, столицы которых имеют коды 763, 3014 и 3243. Выделим значения их площадей и найдем среднее значение (88479,33333). Округлим данное значение и получим число 88479.
